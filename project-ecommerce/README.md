# Online Shoe Store

This web application is an online shoe store created during the learning process. It includes functionality for viewing, searching, and filtering products, as well as adding products to favorites and managing users.

## Features

- **Shoe Catalog View**: All available products are displayed in the catalog.
- **Search and Filtering**: Users can filter by various criteria (brand, size, price, etc.).
- **Product Sorting**: Sort by popularity, price, and novelty.
- **Product Page**: Detailed information on each product with the ability to switch images and select size.
- **Adding to Favorites**: Users can add products to favorites for quick access.
- **Registration and Login**: Users can create accounts and log in.
- **Responsiveness**: The application displays correctly on various devices thanks to responsive design.

## Technology Stack

- **Frontend**: React, CSS (Flexbox, Grid)
- **State Management**: Context API
- **User Interface**: HTML, CSS
